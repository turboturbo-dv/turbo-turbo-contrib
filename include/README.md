# About

This mod supplies TurboTurbo profiles for community-created locomotives. If you
would like to contribute, please submit a pull request to
https://github.com/turboturbo-dv/turbo-turbo-contrib or contact @geluk
on the official Derail Valley Discord server.

If you are the author of one of these locomotives, and you would like to supply
your own profile, you also have the option of distributing it alongside your
mod. Configure the load order such that your mod loads before the community
profiles mod, to allow your profile to override any profiles included here.
